# Harness Config

Ce depot versionne ma configuration OpenCode : commandes, skills et fichiers de support utiles pour mes workflows d'agents IA.

## Origine des skills

Les skills presents dans ce depot viennent principalement de deux sources :

- Romain Lanz : https://github.com/RomainLanz
- Matt Pocock, via son depot `skills` : https://github.com/mattpocock/skills

Ils peuvent etre conserves tels quels ou adaptes localement selon mes besoins.

## Utilisation

Cette configuration est utilisee avec :

- OpenCode
- Codex / ChatGPT

Le but est de garder un historique propre de mes prompts, commandes et skills afin de pouvoir les synchroniser et les reutiliser facilement entre mes environnements.
